# 12C

## How to Run

This project is a single-page app in `/home/runner/work/12C/12C/index.html`.

### Option 1: Open directly
1. Click [`index.html`](./index.html) to open the site.
2. Or open `/home/runner/work/12C/12C/index.html` in any modern browser.

### Option 2: Run with a local server
From `/home/runner/work/12C/12C`, start a simple server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
